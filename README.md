Online School Template

A responsive Persian RTL website template designed for schools, educational institutions, and online learning centers.

Built with React, this project provides a structured landing page for presenting educational services, introducing teachers, and communicating with students and parents.


Live Demo: Coming soon

Features

* Persian language and right-to-left (RTL) layout
* Component-based architecture using React
* Responsive navigation with a mobile menu
* Hero section with primary calls to action
* Educational services section
* Teacher and testimonial sections
* Parent information section
* Custom styling with CSS
* Vazirmatn typography

Tech Stack

* React 18
* JavaScript
* HTML5
* CSS3
* Create React App

Getting Started

Prerequisites

* Node.js
* npm

Installation

Clone the repository:

git clone https://github.com/qplmogi/online-school.git

Navigate to the project directory:

cd online-school

Install dependencies:

npm install

Start the development server:

npm start

Open the local URL shown in your terminal, usually http://localhost:3000.

Production Build

Create a production build:

npm run build

The generated files will be available in the build/ directory.

Customization

The template can be adapted to different schools and educational institutions by updating:

* School name and branding
* Colors and typography
* Educational services
* Teacher information
* Testimonials and school content
* Contact information and call-to-action links

Before using the template for a real school, replace placeholder content and connect all navigation links and buttons to their intended destinations.

Current Scope

This repository contains a front-end website template.

A backend, content management system, authentication, and online enrollment functionality are not included in the current implementation.
